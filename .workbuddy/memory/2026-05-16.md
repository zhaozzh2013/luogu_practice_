## 洛谷刷题助手 Flutter Windows 应用
创建了一个完整的 Flutter Windows 桌面应用「洛谷刷题助手」：

### 项目结构
```
lib/
├── main.dart                    # 入口
├── theme/app_theme.dart         # Tokyo Night 暗色主题
├── models/problem.dart          # 数据模型
├── services/
│   ├── luogu_service.dart       # 洛谷 API 爬虫服务（lentille-context）
│   ├── vscode_launcher.dart     # VSCode 外部编辑器集成
│   └── solution_manager.dart    # 本地文件管理（模板生成）
├── pages/
│   ├── home_page.dart           # 主页面：左右分栏布局 + 爬虫集成
│   └── problem_detail_page.dart # 问题详情页
└── widgets/
    └── problem_widgets.dart     # 可复用组件
```

### 核心设计
- **左右分栏**：左侧 300px 问题列表 + 右侧详情区
- **暗色主题**：Tokyo Night 风格配色
- **🔥 实时爬虫**：通过 x-lentille-request 请求头从洛谷抓取题目列表和详情（16490+ 题）
- **难度筛选**：按洛谷难度等级（1入门→7NOI）筛选
- **搜索**：题号/标题搜索（走洛谷 API）
- **无限滚动**：自动加载分页
- **VSCode 集成**：一键在 VSCode 中创建并打开代码模板
- **本地文件管理**：自动在 ~/Documents/luogu-solutions/ 下生成 C++/Python 模板和题目笔记
- **进度跟踪**：已做/完成率统计

### 构建说明
VS Build Tools 正在后台安装中（~10min）。
安装完成后运行 `flutter build windows --release` 构建。
